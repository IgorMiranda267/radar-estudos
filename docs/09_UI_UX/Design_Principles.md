# Princípios de Design

1. **Simplicidade** - Interface limpa e intuitiva
2. **Consistência** - Elementos visuais uniformes
3. **Acessibilidade** - Compatível com dispositivos móveis
4. **Foco no Usuário** - Prioriza a experiência do estudante
5. **Responsividade** - Adapta-se a diferentes tamanhos de tela
6. **Feedback Visual** - Indicações claras de interações
7. **Organização** - Estrutura lógica de navegação
